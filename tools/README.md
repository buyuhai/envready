# tools —— 资源清单工具（不参与主程序编译）

本目录存放"生成与维护资源清单"的一次性/定时脚本。它们**不属于客户端程序**，
只在开发机与 CI 上运行。

按职责分为五个阶段（对应设计文档 10 的 10.3）：

| 阶段 | 目录 | 做什么 |
| --- | --- | --- |
| 探测 | `probe/` | 从官方源找出版本列表（目录页 / 版本索引 JSON / 官方 API） |
| 解析 | `resolve/` | 把版本解析成真实下载地址（含中转页、防盗链、签名重定向） |
| 校验 | `verify/` | 实际发 `GET + Range` 请求，记录状态、大小、类型，识别伪装成功 |
| 生成 | `gen/` | 产出 `client.json` 与 `components/*.json`，写入哈希与 `expect_files` |
| 发布 | `publish/` | 提交到清单仓库（由 CI 执行） |

## 硬性规则

1. **清单不允许手写**——必须由脚本生成。参考实现的组件列表是手写硬编码的，实测已经腐烂。
2. **探测与校验一律用 `GET + Range`，不用 `HEAD`**：实测多个站点对 HEAD 会超时误判。
3. **格式识别基于文件头魔术字节**，不看扩展名。
4. 任何新版本进入清单前，必须完成"实际请求 + 记录大小"，并尽可能计算真实 SHA-256。
